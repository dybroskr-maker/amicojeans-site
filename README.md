# AMICO JEANS — 홈페이지 프로토타입

**보기:** https://dybroskr-maker.github.io/amicojeans-site/

데님 전문 생산 프로모션 회사 아미코진스의 홈페이지 프로토타입입니다. 레퍼런스는 MOD9(modnine.com).

## 대표님 사용법

1. 위 주소를 폰이나 PC 브라우저에서 엽니다.
2. 오른쪽 아래 **의견 남기기** 를 누릅니다 (처음 한 번만 성함 입력).
3. 말씀하실 자리를 화면에서 **클릭**하면 그 자리에 의견을 답니다.
4. 다 적으신 뒤 **의견 N** → **의견 보내기** 를 누르면 카톡·문자로 보낼 수 있게 정리됩니다.

의견은 대표님 브라우저에만 저장됩니다. 보내기를 눌러야 전달됩니다.

## 구성

- 컬렉션 — 수주 확정 스타일
- 프로젝트 — 수주회 일정과 준비/현장 기록
- 브랜드 — 브랜드 소개 / 핏 가이드 / 스토어(구파발 쇼룸)
- 거래처룸 — 로그인 후 오더 진행판 (미리보기)

사진 자리는 촬영 전이라 데님 패턴 블록으로 표시되어 있습니다.
