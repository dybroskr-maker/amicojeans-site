## 왜 옮겼나

홈페이지와 거래처룸이 서로 다른 주소에 흩어져 있었고, 룸이 쓰던 `*.pages.dev` 무료 주소는
위챗에서 "플랫폼이 악용되었을 수 있음" 경고가 떴습니다. 한 도메인으로 합치면서 정리했습니다.

| 주소 | 내용 |
|---|---|
| `https://amico.dybros.co.kr/` | 공개 홈페이지 |
| `https://amico.dybros.co.kr/partner` | 거래처 로그인 · 계정 신청 |
| `https://amico.dybros.co.kr/staff` | 운영자·직원 로그인 |

## 이 저장소에 남은 것

- `index.html` · `login.html` — 새 주소로 넘기는 안내 페이지 (GitHub Pages 로 계속 서빙)
- `report.html` · `spec.html` · `survey.html` — 내부 검토용 문서. 홈페이지에서 링크되지 않아 옮기지 않았습니다.
- `docs/` — 설계 문서

홈페이지 본문·i18n 사전의 원본은 이 저장소의 커밋 이력(2026-08-25 이전)과 `amicojeans/room` 양쪽에 있습니다.
