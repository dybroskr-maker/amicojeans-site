# ADR-0001: 에이전트 지침 역할 분리 유지

- 판정: 확정
- 기록일: 2026-08-27
- 근거: `AGENTS.md`, `CLAUDE.md`, `.github/workflows/agent-worker.yml`

## 맥락

`AGENTS.md`는 이슈 점화부터 검증·자동 머지까지 자동화 절차를 정의한다.
`CLAUDE.md`는 사이트 구조, T2 판정, 검증 정책, 전역 금지와 대표 확정 사항을 정의한다.
워크플로도 두 문서를 모두 읽도록 지시한다.

## 결정

두 파일을 하나로 합치거나 심볼릭 링크로 대체하지 않는다. 각 파일의 역할을 유지하고,
`AGENTS.md`의 참조 지도에서 서로의 책임과 결정 인덱스를 연결한다.

## 기각한 안

내용 일부가 비슷하다는 이유로 한 파일을 다른 파일의 심볼릭 링크로 바꾸는 안을 기각한다.
그렇게 하면 한쪽에만 있는 운영 절차나 위험도 판정이 사라진다.
