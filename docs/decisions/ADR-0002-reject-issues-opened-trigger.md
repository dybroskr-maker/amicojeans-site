# ADR-0002: `issues.opened` 트리거 추가 금지

- 판정: 기각 기록
- 기록일: 2026-08-27
- 근거: `AGENTS.md` 워크플로 폴더 규칙

## 맥락

이슈를 만들면서 자동화 라벨을 붙여도 GitHub는 `labeled` 이벤트를 보낸다.
워커는 이 이벤트로 이미 점화된다.

## 결정

`agent-worker.yml`의 이슈 트리거에 `opened`를 추가하지 않는다.

## 기각 사유

`opened`와 `labeled`를 함께 받으면 같은 이슈로 워커가 두 번 실행되어
브랜치와 PR이 중복 생성될 수 있다.

## 재검토 조건

GitHub 이벤트 동작이나 점화 방식이 바뀌면 실제 실행 기록을 근거로 다시 판단한다.
