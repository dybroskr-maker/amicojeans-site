# ADR-0003: 답변 회수가 끝난 설문 원본 보존

- 판정: 확정
- 기록일: 2026-08-27
- 근거: `CLAUDE.md` 구조·T2 판정·전역 금지

## 맥락

`survey.html`은 대표 확인 답변을 이미 회수한 설문 원본이다.
현재 규칙은 이 파일을 T2 경로이자 수정 금지 대상으로 지정한다.

## 결정

`survey.html`을 수정하지 않는다. 변경 필요가 생기면 일반 워커 작업으로 처리하지 않고
사람이 검토하는 별도 결정으로 올린다.

## 기각한 안

사이트 문구나 화면을 정리하면서 설문 원본까지 함께 고치는 안을 기각한다.
과거 답변의 문맥과 근거가 달라질 수 있기 때문이다.
