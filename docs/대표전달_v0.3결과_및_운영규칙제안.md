## 2. 대표님께 받아야 진행되는 것

| 무엇 | 언제까지 | 없으면 |
|---|---|---|

| **사업자 정보** — 상호·사업자등록번호 | 오픈 전 | 하단 표기가 비어 있습니다 |
| **사진** — 첫 화면 1장, 쇼룸 4장, 스타일 8~12컷 | 수주회 준비와 함께 | 파란 블록으로 남습니다 |
| **도메인 이름** — `amicojeans.com` 으로 갈지 | 이번 주 | 임시 주소를 계속 씁니다 |

## 3. 이제 정해야 할 것 — 번호 체계

거래처룸(오더 관리)을 열려면 **오더마다 고유 번호**가 있어야 합니다. 번호가 없으면 사진도 파일도 어디에 붙일지 정할 수 없습니다.

### 먼저 여쭙습니다

**지금 엑셀에서 쓰고 계신 번호 체계가 있습니까?**
있으면 새로 만들지 않고 그것을 그대로 옮깁니다. 익숙한 번호를 바꾸는 게 가장 큰 혼란입니다.
없거나 매번 다르게 적어 오셨다면 아래를 제안드립니다.

### 오더번호 제안

```
26FW-AB-012
 │    │   └ 일련번호 3자리 (거래처별로 001부터)
 │    └ 거래처 코드 2자리 (회사명 영문 이니셜)
 └ 시즌 (26FW / 26SS)
```

예: A사의 26 F/W 12번째 오더 → `26FW-AB-012`

이렇게 하면 번호만 보고 **어느 시즌, 어느 거래처, 몇 번째 건인지** 바로 읽힙니다.
거래처도 자기 번호가 001부터 순서대로 붙으니 헷갈리지 않습니다.

### 샘플번호 제안

오더번호 뒤에 단계를 붙입니다.

```
26FW-AB-012-S1   1차 샘플
26FW-AB-012-S2   2차 샘플 (수정본)
26FW-AB-012-S3   3차 샘플 … (N차까지)
26FW-AB-012-SF   완성샘플 (승인 후 생산 시작)
26FW-AB-012-SP   생산샘플
```

**여기서 여쭙습니다 — 실제로 쓰시는 용어가 무엇입니까?**
1차/2차/컨펌/세일즈샘플처럼 현장 용어가 따로 있으면 그 말을 그대로 씁니다.

### 사진·파일 이름도 같이 갑니다

```
26FW-AB-012-S2_front_01.jpg
26FW-AB-012-S2_detail_03.jpg
```

번호를 정해 두면 사진이 자동으로 그 오더 카드에 붙습니다. 지금처럼 카톡 앨범을 뒤질 일이 없어집니다.

## 4. 계정과 권한

### 계정은 세 종류입니다

| 누구 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| **대표님** | 전체 오더 · 원가 · 공장 · 계정 관리 | 전부 |
| **직원** | 담당 거래처 오더 · 원가 | 상태 변경 · 사진 올리기 · 코멘트 |
| **거래처 담당자** | **자기 회사 오더만** · 진행 상태 · 사진 · 납기 | 코멘트 · 확인 · 수주회 예약 |

거래처 화면에는 **원가와 공장 이름이 아예 나오지 않습니다.** 화면에서 숨기는 게 아니라 데이터 자체가 넘어가지 않게 막습니다.

### 로그인 방식 — 비밀번호를 안 만드는 쪽을 권합니다

거래처 담당자에게 비밀번호를 만들게 하면 반드시 잊어버립니다. 그러면 그날로 카톡으로 돌아갑니다.
**이메일로 온 링크를 누르면 로그인되는 방식**을 권합니다. 외울 게 없습니다.

**여쭙습니다 — 대표님과 직원분들은 어느 쪽이 편하십니까?**
① 전부 링크 로그인 ② 대표·직원은 아이디+비밀번호, 거래처만 링크 ③ 전부 아이디+비밀번호

### 사람이 바뀌면

담당자 퇴사·교체는 **계정 하나를 끄면 즉시 차단**됩니다. 비밀번호를 바꿀 필요도, 다른 사람에게 영향도 없습니다.

## 5. 운영 화면(대시보드) 제안

대표님이 로그인하면 보이는 첫 화면입니다.

| 구역 | 내용 |
|---|---|
| **오늘 볼 것** | 지연된 오더, 오늘 입고 예정, 확인 기다리는 건 |
| **오더 보드** | 샘플 → 확정 → 생산 → 출고 4단 칸에 카드가 놓임. 끌어서 옮기면 상태 변경 |
| **거래처** | 회사 목록, 담당자, 계정 상태, 시즌별 오더 수 |
| **스타일·샘플** | 스타일별 샘플 이력(1차→2차→확인), 사진 |
| **설정** | 계정 발급·차단, 거래처 코드, 시즌 열기/닫기 |

**여쭙습니다 — 이 다섯 개 중 대표님이 매일 여실 화면은 무엇입니까?**
그것을 첫 화면으로 놓고 나머지는 뒤로 보내겠습니다.
