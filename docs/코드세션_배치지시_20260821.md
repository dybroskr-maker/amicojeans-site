## 1. 배치 2 — 공개 사이트 v0.3 (대표 설문 반영) [T1]

`index.html` 을 수정한다. **아래 12건이 전부이며 목록에 없는 변경은 하지 않는다.**
확정 사항의 정본은 `CLAUDE.md` 「대표 확정 사항」 표다.

히어로·컬렉션 그리드·프로젝트 타임라인·브랜드 3탭·거래처룸 미리보기·핀 코멘트 리뷰 기능은
**이미 있다. 재구현하지 않는다.**

1. **사무실 주소 정정 (최우선)** — 소스·문서 전체에서 `구파발` 제거.
   실제 주소는 `경기도 고양시 덕양구 동충로 70 (현대프리미어캠퍼스)` 이나
   **노출은 「경기 고양시 덕양구」까지만** 한다. 전체 주소는 소스에 넣지 않는다.
   쇼룸 명칭 `구파발 쇼룸` → `고양 쇼룸`.

2. **홈에서 컬렉션 사진 제거** — 홈의 컬렉션 섹션을 텍스트 구성으로 바꾼다.
   홈에서 보이는 사진은 히어로 1장뿐이 되게 한다. (대표 요청 원문: 글자만 또는 메인 사진만)

3. **히어로 자리표시자 라벨** → `워싱 원단 클로즈업`.

4. **헤드라인** — 「데님 한 종목만 한다」가 첫 화면의 주장이 되게 강조를 조정한다. 전면 교체가 아니다.

5. **메뉴에 「문의」 추가** — 컬렉션·프로젝트·브랜드·**문의** + 거래처 로그인.
   내용은 견적·생산 문의 안내, 연락처 자리, 문의 시 알려 줄 항목(품목·수량·시즌·희망 납기), 방문 예약 안내.
   **폼 전송 기능은 넣지 않는다**(서버 없음). 메일 링크로 한다.

6. **컬렉션을 로그인 전용으로** — 메뉴는 유지, 비로그인 시 안내 화면 + 로그인 버튼.
   기존 카드 마크업은 삭제하지 말고 로그인 후 화면용으로 보존한다.

7. **핏 가이드도 로그인 전용** — 같은 방식. 핏 5종 구성과 치수표는 보존(대표가 5종 유지 확정).

8. **상품 정보 표기** — 로그인 후 화면 기준 원단 중량·워싱까지. 사이즈 스펙·거래처명은 넣지 않는다.

9. **중국 사무소** — 도시명 노출 금지. `중국 생산 사무소` 로만.

10. **대표 이력** — 학교명·연도 금지. `이탈리아에서 패션을 공부했다` 수준.

11. **거래처룸 미리보기 문구** — 거래처 공개 범위를 `진행 상태 + 진행 사진 + 납기 일정` 으로 표기.
    원가·공장명은 계속 비공개.

12. **글꼴 교체 지점 명시** — 서체를 CSS 변수 한 곳에서 바꿀 수 있게 정리하고
    `--disp` / `--body` 위에 「서체 교체 지점」 주석을 단다. 후보 서체를 추가하지는 않는다.

### 검증 (T1)

`node scripts/gate.mjs` 1회 → 통과해야 한다(1번 항목을 제대로 하면 통과한다).
배포 후 육안 확인 3항목이면 충분하다 — 소스에 `구파발` 0건 / 홈에 사진 1장 / 메뉴 4개 + 로그인.

## 2. 배치 3 — 3개국어 [T1]

대표가 한국어 + 영문 + 중문을 요청했다.

- 화면 문구를 `i18n/ko.json` · `en.json` · `zh.json` 으로 분리, `index.html` 이 읽어 렌더
- 언어 토글은 헤더 우측. 선택은 `localStorage` 에 저장
- 기본 한국어. 첫 방문 시 브라우저 언어가 `zh` 계열이면 중문, `en` 계열이면 영문
- **중문은 간체.** 브랜드 문구는 직역하지 말고 의미 중심으로
- 고유명사 고정: `AMICO JEANS` / `아미코진스`
- 번역 문구는 대외 공개물이므로 T0이 아니라 **T1** 로 다룬다
- `survey.html` 은 다국어화하지 않는다 (역할이 끝난 페이지)

## 3. 배치 4 — 거래처룸 저장소 [T2 · 선행 조건 실측 후]

**먼저 실측한다.**
- 조직 `amicojeans` 가 존재하는가
- Supabase 프로젝트가 있는가 (`SUPABASE_DB_URL` 시크릿 존재로 판정)

**하나라도 없으면 실행하지 말고 무엇이 없어서 중단했는지만 보고한다.**
없는 상태에서 골격만 만들면 나중에 경로가 어긋난다.

둘 다 있으면: 저장소 `room` 생성 → 정적 SPA 골격 + `supabase/0001_schema.sql`.
스키마·RLS 정본은 `docs/거래처룸_권한설계.md` 다.
**단 거래처 노출 범위는 대표 확정에 따라 「진행 상태 + 사진 + 납기」 까지다** — 문서와 다르면 대표 확정이 우선.
오더 단계는 4단계(샘플→확정→생산→출고)로 확정.
